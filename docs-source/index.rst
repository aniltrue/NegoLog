NegoLog documentation
=====================

NegoLog is a Python framework for bilateral automated negotiation and
opponent-model assessment. These pages describe the public code revision used
to build them. The repository's older ``docs/`` HTML is a historical snapshot.

Start with the repository README for installation, the CLI quickstart and the
local web interface. Record the Git revision, configuration, input profiles,
dependency versions and random seed when comparing runs. Model accuracy and
negotiation performance are separate measurements; these pages do not claim a
performance ranking.

Repository guides from this build:
:download:`README <../README.md>`,
:download:`migration notes <../MAINTENANCE.md>`, and
:download:`contribution guide <../CONTRIBUTING.md>`.
