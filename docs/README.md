# Looking for the NegoLog user guide?

Start with the [current repository README](../README.md), then choose:

- [Your first tournament](../docs-source/getting-started.rst): installation,
  CLI and local browser workflow, and how to read the results.
- [Configure and extend](../docs-source/tutorials.rst): complete YAML examples
  and your first agent/logger module.
- [Component catalog](../docs-source/components.rst): built-in agents, models,
  and logger choices.
- [Troubleshooting](../docs-source/troubleshooting.rst): common problems and
  concrete fixes.
- [Build the complete current HTML documentation](../docs-source/README.md).

The HTML files **in this directory** are a historical generated snapshot. They
omit current models and API changes, including the abstract estimated-preference
migration. Use the guides above for the current checkout and
[MAINTENANCE.md](../MAINTENANCE.md) when updating older code.

The current documentation build writes to a separate output directory. This
notice preserves the historical pages and does not republish them as current.
